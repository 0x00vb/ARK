# Product

## Register

product

## Users

People working on project conversations, software, games and creative files on their own or a connected computer. The owner requests clearer, more consistent Desktop colors, layout and icons.

## Product Purpose

ARK helps people ask for work, inspect results, respond to approvals and revise editable project files. Plugins expose optional capabilities without requiring a second navigation model.

## Brand Personality

Calm, precise, human. Source: ../ark-site/BRAND.md.

## Anti-references

Decorative gradients, saturated inactive icons, card grids without a purpose, technical setup in ordinary tasks and claims of availability before verification. Codex is a quality reference for clarity and density; ARK retains its Projects, Chats and Agents model.

## Design Principles

- Keep the conversation and the person’s unfinished work intact.
- Use the same visual vocabulary for the same action.
- Expose optional setup where the person chooses the capability.
- Show prerequisites and actual results, never inferred installation status.

## Accessibility & Inclusion

Preserve keyboard navigation, visible focus, reduced motion, readable light and dark themes, narrow layouts and coarse-pointer targets. Existing workspace and brand rules remain authoritative.
